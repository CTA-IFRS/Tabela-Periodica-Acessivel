# Tabela Periódica Acessível
A Tabela Periódica Acessível é uma ferramenta desenvolvida pelo CTA para garantir o acesso inclusivo à Química. Com foco em acessibilidade, oferece navegação por teclado, leitura por leitores de tela, filtros, buscas e visualização adaptada. Baseia-se em pesquisas técnicas e nas diretrizes da WCAG.

Para mais informações acesse a página do projeto: https://cta-ifrs.github.io/Tabela-Periodica-Acessivel
